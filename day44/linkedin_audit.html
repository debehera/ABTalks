Publish Post #2 — lessons-learned / hot take

Niche: Legacy-to-cloud security.

Unpopular opinion: most "cloud migration" projects fail at security not because teams don't know AppSec — but because security gets bolted on after the migration is "done." Every legacy-to-Azure migration I've led starts with the security model, not the infrastructure model. OWASP practices get built into the pipeline before the first workload moves, not after an audit flags it. It's slower on day one. It's dramatically faster by month three, because you're not re-architecting access controls on a system that's already live. If you're planning a legacy migration this year — what's your team's security checkpoint, and when does it happen in the timeline?

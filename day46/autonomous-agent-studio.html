Architecture overview

  • Planner — decomposes the research question into a section outline and rubric emphasis before any drafting begins.
  • Executor — writes the first full draft brief from the plan.
  • Evaluator — scores the current draft 0–100 against the rubric and returns structured reasoning, called fresh every round.
  • Critic — reads the Evaluator's report and identifies the highest-leverage weaknesses, independent of the score itself.
  • Improver — rewrites the full draft addressing the Critic's points, receiving prior score + critique as input.
  • Memory Manager — after each round, records what changed and why, so recurring issues aren't reintroduced.
  • Safety Monitor — screens each draft for unverifiable claims presented as fact or unlicensed financial-advice framing.
  • Final Reviewer — polishes the winning draft into a publish-ready brief once a stop condition fires.

Extension ideas

  • Add a live web-search tool call for the Executor/Improver so figures cite retrievable sources rather than model recall.
  • Run two Critics in parallel (bull case / bear case) and have the Improver reconcile both before revising.
  • Persist Memory Manager notes to a vector store so future briefs on related tickers inherit prior lessons.
  • Add a human-in-the-loop approval gate before Final Reviewer publishes, with inline edit-and-resubmit.
  • Swap the stop check for a multi-metric threshold (rigor AND balance AND clarity each ≥ target) instead of one score.

What is this?

A quick tour of the Personal AI Playbook

This is a personal toolkit for working with AI models (Claude, GPT, Copilot, Gemini) as a software engineer. Instead of hundreds of one-off prompts, it gives you reusable workflows — templates with fill-in-the-blank variables — plus two builder tools for creating your own prompts from scratch.

1
Dashboard

An overview of your saved workflows, grouped by task category (architecture, debugging, code review, docs, learning, data analysis).

2
Workflows

Ready-made prompt templates for recurring engineering tasks. Each has editable variables, a live-filled preview, an example, best practices, and a one-click copy button.

3
Prompt Builder

Assemble a custom prompt from building blocks — Role, Objective, Context, Constraints, Reasoning strategy, Output format, Tone, Examples, Quality checks — with a live preview as you go.

4
Loop Builder

Turn any prompt into a self-checking, iterating prompt by defining a goal, how to judge each attempt, how to improve it, and when to stop.

5
Building Blocks

A reference library explaining every block used by the two builders, so you always know what each piece does and why it's there.

Everything you create is saved to this browser's local storage — nothing leaves your machine. Use Export anytime to back it up as a JSON file.

What this tool does

The Personal AI Playbook stores reusable AI prompt systems so you stop re-explaining the same context every time. Use Workflows for ready-made templates, the Prompt Builder to assemble a custom prompt from labelled building blocks, and the Loop Builder to turn any prompt into one that iterates and checks its own work.

Loop Builder

Turn any prompt into an autonomous looping prompt — one where the AI evaluates its own output against your criteria, revises it, and repeats until it meets the bar or hits a stop condition. Useful for refactors, test generation, and polishing docs without you babysitting every pass.

This is the task the AI repeats and refines each iteration — e.g. "Refactor this function for readability."
The single outcome that ends the loop successfully. Without this the AI won't know when to stop improving.
How the AI judges its own output after each pass — turns "looks fine" into a measurable check.
Defines what the AI actually does differently between iterations, instead of repeating the same attempt.
Prevents an endless loop — stop on success, on a score threshold, or after a fixed number of tries.
